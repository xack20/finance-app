# M4-6 — Conversational Agent UI + Wiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire the tested agent core (M4-1…M4-4) into a usable Compose feature: a chat `AgentScreen` where a typed money story/question runs the ReAct loop, proposed writes are reviewed and applied atomically, and the conversation persists.

**Architecture:** A new `AgentRuntime` (commonMain) is the single integration seam — it resolves the cloud `AgentProvider` (gated by a distinct agent consent + BYO key), holds the assembled `ToolRegistry`, builds the system prompt, runs `AgentLoop`, and applies via `WriteBatchCommitter`. `AgentViewModel` orchestrates the turn lifecycle + persistence (`ConversationRepository`). Compose screens (`AgentScreen`, `ReviewCard`) follow the existing design system (`LocalHisaabPalette`, `LocalAppContainer`) and reuse field composables extracted from `EntryScreen`.

**Tech Stack:** Kotlin Multiplatform, Compose Multiplatform, kotlinx-coroutines, SQLDelight/SQLCipher, kotlin.test + kotlinx-coroutines-test (logic), `androidInstrumentedTest` Compose UI tests (screens).

**Two test tiers:**
- **Logic** (AgentRuntime, AgentViewModel, ConversationRepository addition, registry assembly): `commonTest` with `FakeAgentProvider` + in-memory repos / FK-enforced `TestDatabase`. Run via the subagent TDD loop.
- **Compose screens** (AgentScreen, ReviewCard, consent dialog, FAB, card inputs): built to mirror existing screens (`ReviewInboxScreen`/`EntryScreen`/`AccountsScreen`) + the app theme; verified by `androidInstrumentedTest` (mirrors `ReviewInboxScreenTest`) and a manual emulator smoke. For these, the **instrumented test is the acceptance spec**; the composable body follows the existing components — do NOT invent a new visual language.

**Out of scope (touchpoints only):** real STT (M4-5; mic button disabled + `speechToText` stub), polished consent screen + per-state messages + full `LlmError`→UI (M4-7; minimal gate here), iOS run (M4-0; iOS actuals declared so the module compiles).

```kotlin
// AgentRuntime.kt
package app.hisaab.agent
import app.hisaab.data.AccountRepository
import app.hisaab.data.CategoryRepository
import app.hisaab.data.InsightRepository
import app.hisaab.data.MerchantRepository
import app.hisaab.data.PersonRepository
import app.hisaab.data.TransactionRepository
import app.hisaab.llm.LlmError
import app.hisaab.llm.LlmException
import kotlinx.datetime.Clock
import kotlinx.datetime.TimeZone
import kotlinx.datetime.toLocalDateTime

sealed interface AgentAvailability {
    data object Ready : AgentAvailability
    data class Unavailable(val reason: String) : AgentAvailability
}

fun buildAgentToolRegistry(
    accounts: AccountRepository, categories: CategoryRepository, merchants: MerchantRepository,
    txns: TransactionRepository, insights: InsightRepository, persons: PersonRepository,
): ToolRegistry = ToolRegistry(
    readTools = listOf(
        ListAccountsTool(accounts), AccountBalancesTool(accounts), ListCategoriesTool(categories),
        FindMerchantTool(merchants), QueryTransactionsTool(txns), SpendByCategoryTool(insights),
        PersonBalanceTool(persons), CardSummaryTool(accounts),
    ),
    writeDescriptors = agentWriteDescriptors(),
)

/** Integration seam. Loop stays db-free; the committer is the only writer. */
class AgentRuntime(
    private val registry: ToolRegistry,
    private val provider: AgentProvider?,
    private val isConsented: suspend () -> Boolean,
    private val accountNames: suspend () -> String,
    private val categoryNames: suspend () -> String,
    private val committer: WriteBatchCommitter,
    private val todayIso: () -> String = {
        Clock.System.now().toLocalDateTime(TimeZone.currentSystemDefault()).date.toString()
    },
    private val language: String = "English/Bengali/Banglish",
    private val maxIterations: Int = 6,
) {
    suspend fun availability(): AgentAvailability = when {
        !isConsented() -> AgentAvailability.Unavailable("Turn on the assistant (a cloud feature) to continue.")
        provider == null -> AgentAvailability.Unavailable("Add a cloud model + API key in Settings to use the assistant.")
        else -> AgentAvailability.Ready
    }

    suspend fun run(history: List<ChatMessage>, userMessage: String): AgentTurnResult {
        val p = provider ?: throw LlmException(LlmError.InvalidKey)
        val system = AgentPrompts.system(registry, accounts = accountNames(), categories = categoryNames(),
            todayIso = todayIso(), language = language)
        return AgentLoop(p, registry, systemPrompt = system, maxIterations = maxIterations).run(history, userMessage)
    }

    suspend fun apply(writes: List<ProposedWrite>): AppliedSummary = committer.apply(writes)
}
```

## Task 3: `AgentViewModel` + turn lifecycle

**Files:** `screens/agent/AgentViewModel.kt`, test `screens/agent/AgentViewModelTest.kt`.

State: `AgentUiState(conversationId: String? = null, messages: List<AgentMessage> = emptyList(), input: String = "", inFlight: Boolean = false, review: List<ProposedWrite> = emptyList(), reviewIncluded: Set<Int> = emptySet(), assistantMessageId: String? = null, gate: AgentAvailability? = null, error: String? = null)`. Intents: `onInputChange(String)`, `onSend()`, `onMicTap()` (no-op while disabled), `onToggleInclude(Int)`, `onEditWrite(Int, JsonObject)`, `onApply()`, `onNewChat()`, `onConsent()`.

Lifecycle:
- init: `conversationId = latestConversationId() ?: createConversation()`; collect `observeMessages(conversationId)` into `messages`.
- `onSend()`: `val text = state.input.trim()`; clear input. `when (runtime.availability())`: `Unavailable -> set gate`; `Ready ->` `appendUserMessage(convId, text)`; `inFlight=true`; build `history` = current `messages` mapped to `ChatMessage` (USER→Role.USER, ASSISTANT→Role.ASSISTANT, content only); `runCatching { runtime.run(history, text) }`; on success: `val mid = appendAssistantMessage(convId, res.finalMessage, res.proposedWrites, null)`; set `review=res.proposedWrites, reviewIncluded=indices, assistantMessageId=mid`; on failure (LlmException): `error = "Something went wrong — nothing was saved."`; always `inFlight=false`.
- `onToggleInclude(i)`: flip `i` in `reviewIncluded`. `onEditWrite(i, args)`: replace `review[i]` with `ProposedWrite(review[i].tool, args)`.
- `onApply()`: `val included = review.filterIndexed { i,_ -> i in reviewIncluded }`; `runCatching { runtime.apply(included) }`; on success: `assistantMessageId?.let { recordApplied(it, summary) }`; clear `review/reviewIncluded`; set a confirmation (e.g. `error=null`, maybe a transient message); on failure: `error = "Couldn't save — rolled back."` (review stays for retry).
- `onConsent()`: store consent (via a passed `setConsent: suspend ()->Unit` seam), clear `gate`. `onNewChat()`: `conversationId = createConversation()`, reset review.

VM ctor: `AgentViewModel(conversationRepo: ConversationRepository, runtime: AgentRuntime, setConsent: suspend () -> Unit, scope: CoroutineScope = CoroutineScope(SupervisorJob() + Dispatchers.Main))` — mirror `AutoCaptureViewModel`'s scope/dispatcher seam so tests inject `StandardTestDispatcher`.
